# 需要你协助的事项

本文件只集中账号授权、真实使用环境和主观验收；不要求注册新账号，也不要求把密码、Cookie、token、PIN 或私钥发到聊天中。开发与本地验收仍由助手负责，不能把未完成开发转交给你。当前构建和逐项技术范围见 [CURRENT_STATUS.md](CURRENT_STATUS.md#剩余主线)。

执行顺序：先做第1/2项中你实际使用的服务；第3项只补你手机仍发生的问题；第4项是日常设备体验，不是注册账号前提。无需你配合的开发与本地验收由助手处理：C150已修历史APK导出失败，正常导出/限定恢复/显式发布者确认/真实DEX闭环完成，原业务数据与信任pin不变；不是把整库强行合入另一设备。Windows安全存储已修并实际开启/失焦/冷启/解锁/关闭还原，不索要PIN/Windows凭据。

## 1. 追踪服务真实双向写入（P10）

- [ ] 在 Triomi「我的 → 追踪账号」里，自己登录已有 Bangumi 或 AniList 账号；只需要你希望使用的服务，不需要两个都注册。
- [ ] 指定一个允许测试的作品链接或远端条目 ID，以及允许写入的**状态、评分、进度**；分别说明哪些字段不能修改。
- [ ] 明确是否允许制造一次冲突、以及验收后是否还原原值。未授权的字段与其他作品不会改动。

验收：预览原值 → 逐字段确认 → 推送 → 重新读取服务端值 → 对照一致；拒绝/冲突不静默覆盖，本地进度不倒退。已有本地契约测试不能替代这次远端实写。

## 2. 外部 WebDAV 和两设备同步（P11）

- [ ] 在应用云同步设置中填写已有服务地址和账号；不要在这里粘贴认证信息。
- [ ] 指定一个可以写入的**独立空测试目录**，并允许创建版本文件、重读以及删除本次自己创建的文件；不得使用需要覆盖原备份的目录。
- [ ] 选择测试范围：仅元数据，或明确包含指定离线媒体；如希望验收两设备同步，准备另一台安装相同发布版本的设备。

验收：上传 → 新进程重读 → 另一设备预览/合并 → 版本冲突不覆盖 → 对照书架/进度/所选媒体 hash；仅清理本次文件。本机 loopback、257MiB 往返与 CAS 冲突证据不等于外部服务已通过。自动备份仅元数据；云端不携带可执行规则、APK、账号或发布者信任。

## 3. 你实际手机上的 Mixn LK 慢 / LNS 连接失败

- [ ] 提供 Mixn 版本、Android 版本、故障发生的大致时间和时区；不需要账号信息。
- [ ] 同一手机、同一网络下分别尝试 Mixn 与站点网页，记录“打开到出现目录”的用时和**完整错误文字**；Wi‑Fi/移动网络各做一次即可。
- [ ] LNS 如需重新登录，请自己在应用内操作；说明登录后是否仍失败。不要导出会话、整份网络抓包或包含凭据的日志。

已有结论：C148主机公开请求中LK默认DNS1.95–6.64秒、一次超时；同接口保持域名/SNI/TLS但使用当次已解析路由约2秒，Mixn依次12秒备用路由可能放大等待。LNS主/备用hub均完成握手并正常拒绝游客调用，远端主动公告攻击停站后已恢复，未发现接口废弃证据。以上不能证明你手机当前根因或本人会话有效。这里只补真实故障环境，不需要修改DNS、关闭TLS或绕过验证；如果现在已恢复，注明恢复时间即可，不要求再次制造故障。

## 4. 物理设备阅读体验

- [ ] 如你使用 TalkBack，确认来源开关、阅读目录及翻页的系统读屏语义和焦点顺序；应用内小说朗读与 PIN 产品功能已按本轮要求移除，无需听音或提供 PIN。
- [ ] 用你实际阅读的长条/超大图漫画检查裁边、双页和自动滚动是否符合预期；提供作品来源、阅读模式、屏幕方向和不含账号信息的异常截图即可。

验收：不丢原进度、旋转后位置合理，正文/图片/视频在实际屏幕可读。模拟器已覆盖的具体路径保留证据，不要求你重复所有开发者测试。

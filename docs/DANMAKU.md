# 弹幕接入与播放器行为

## 当前能力

播放器已开放弹幕显示开关、显示/屏蔽设置、来源弹幕重新加载，以及使用本人应用身份的官方搜索/匹配/发送入口。Android、iOS 和 Windows 共用 Dart 解析与绘制层；Android Media3、iOS AVPlayer 和 Windows media_kit 的实际播放位置分别驱动同一弹幕时间轴。系统 iOS PiP 显示原生视频层，不包含 Flutter 自绘弹幕层。

| 路径 | 授权要求 | Triomi 行为 |
| --- | --- | --- |
| 来源规则声明 `content.danmakuUrl` / `danmaku` | 来源自身允许应用读取 | 按来源网络客户端请求弹弹play兼容 JSON，自动加载；不需要弹弹play AppId/AppSecret |
| 官方搜索、匹配与拉取 | 用户自己的 AppId/AppSecret | 凭据未配置时明确引导设置，不借用其他应用身份 |
| 官方发送 | 本人应用身份、账号 token，且已匹配当前剧集 | 用户主动输入并发送；无权限/未匹配时拒绝，不假报成功 |
| 本地 XML/JSON 文件、自托管端点配置 | 各自独立 | 目前没有专门导入/自定义服务设置入口；不能把来源 URL 字段称为完整文件导入能力 |

## 操作

1. 打开有合法视频线路的剧集。来源带有兼容弹幕地址时自动加载。
2. 播放器顶部的弹幕按钮可立即开关显示；播放设置中的「弹幕设置」调整透明度、字号、速度、位置和屏蔽词。
3. 来源弹幕加载失败不终止视频。播放设置中的「重新加载来源弹幕」显示错误并可重试；网络响应不应被伪装成已成功获取弹幕。
4. 官方匹配/发送需要在通用设置中的「弹幕设置」填写本人凭据。没有凭据仍能显示来源弹幕，不能据此推导官方接口免认证。

切集会先清空上一集弹幕、匹配剧集 ID 和请求归属；异步结果必须仍属于当前剧集与当前加载请求才能发布。暂停时弹幕冻结，拖动/跳转重新定位时间轴；关闭显示清理当前可见弹幕。

## 凭据与证据边界

不内置或提取其他应用私有 AppSecret，也不从参考应用安装包复制身份。AppSecret/token 由现有安全存储保存，不进入备份或日志。官方接入要求见[弹弹play官方文档](https://doc.dandanplay.com/open)。

项目的 loopback 夹具覆盖兼容 JSON、播放器开关、切集迟到响应和实际视频时间轴，不代表任意外站、官方账号或 iOS 真机全部通过。当前构建/运行结果以 [CURRENT_STATUS.md](CURRENT_STATUS.md) 为准；iOS 安装与平台限制见 [IOS_ADAPTATION.md](IOS_ADAPTATION.md)。

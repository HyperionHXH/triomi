## 交付内容

### 1. 下载管理（小说 + 漫画）
- **数据层**：`downloads` 表（drift，`schemaVersion 2` 起沿用）记录任务状态、进度、
  失败原因、离线路径；`DownloadRepository` 提供入队 / 状态流转（queued → running →
  done/failed）/ 按作品分组 / 待处理队列 / 离线正文读写 / 离线图片目录。
- **执行器**：`DownloadService` 串行执行任务——
  - 小说：正文 JSON 落 `chapters.content_json`（体积小、随备份走）；
  - 漫画：图片落 `<文档>/downloads/<sourceId>/<item>/<chapter>/`，写
    `manifest.json` 记录有序文件名，`downloads.path` 存目录；
  - **锁定章节一律拒下**（延续「不解锁、不缓存、不导出」的红线）。
- **队列控制器**：`DownloadController`（AsyncNotifier）串行 pump、失败重试、
  清理已完成记录、删除整本（记录 + 离线文件）；**仅 WiFi 下载**开关
  （`NetworkInterface` 判断 `wlan*`/`en0`，无插件实现）。
- **下载管理页**：仅 WiFi 开关、按作品分组卡片（类型图标 / 标题 / 完成度 / 进度条）、
  重试、清理、删除、**点击进入作品详情**。
- **离线优先读取**：小说阅读器与漫画阅读器都**先读本地**（命中则完全不发网络请求）；
  详情页在来源取数失败时**自动回退本地缓存**（作品快照 + 目录），并显示
  「离线模式」提示条。

### 2. 备份导出 / 导入
- 单文件 zip：`data.json`（作品 / 书架 / 进度 / 历史 / 目录缓存（含已下载正文）/
  设置）+ `covers/`（封面图）。
- **不导出凭据类设置**（键名含 password / token / security_key / secret 一律跳过）。
- 导入按**更新时间较新者胜**合并，不覆盖本机更新的进度；历史按访问时间去重。
- 入口在「我的 → 备份与恢复」：导出完整/精简备份、列出本地备份、一键导入。

### 3. WebDAV 同步（多设备零服务器方案）
- `WebDavClient`：MKCOL 建目录 → PUT 上传 / GET 下载 / PROPFIND 取远端大小与时间，
  Basic 认证；405 视为目录已存在，404 视为无备份。
- 页面支持服务器地址 / 用户名 / 密码 / 远端目录配置、保存并检测、上传本机备份、
  拉取远端备份并合并；远端时间按本机时区显示。
- 夹具服务新增最小 DAV 实现（MKCOL / PUT / GET / PROPFIND + 目录穿越防护）供联调。

### 4. 弹幕增强
- 播放器控制条新增：**弹幕开关 / 弹幕设置 / 弹幕搜索 / 发送**、**倍速菜单**。
- 倍速 0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 2.0 / 3.0（`Player.setRate`）。
- `DanmakuSettings`：开关、不透明度、字号、速度倍率、显示类型（滚动/顶部/底部）、
  屏蔽词列表；持久化并按设置过滤（屏蔽词命中即隐藏，速度倍率缩短滚动停留时间）。
- 弹弹play 凭据设置入口（appId / appSecret / token）；**发送弹幕等真实联调**
  （缺 token 时明确提示先去配置，不静默失败）。

## E2E 发现并修复的问题

1. **下载全失败 + 列表标题显示 remoteId**：下载执行器只用 `remoteId` 构造章节，
   而正文地址需要目录里的 `url`；且入队时没有落作品快照。
   → 执行器改用 `repository.chapterOf()` 取带 url 的章节行；入队前先
   `cacheItem` + `saveChapters` 写库（列表也因此能显示标题）。
2. **目录刷新会抹掉已下载的正文**（数据丢失级）：`LibraryRepository.saveChapters`
   是先 delete 后 insert，已下载的 `content_json` 被一并删除。
   → 重建目录前先读出既有 `content_json`，按 remoteId 原样带回（回归测试已覆盖）。
3. **断网后详情页打不开**，离线正文因此没有入口：
   → 详情页加本地缓存回退（作品快照 + 目录，目录为空时不回退）；
   下载管理页分组卡片恢复「点击进入作品」。
4. **断网时请求挂死 20 秒以上才失败**：dio 只设了 send/receive 超时，没有
   connectTimeout，连不上的主机一直挂起。
   → 三处请求统一补 `connectTimeout`。
5. **夹具视频端点 Range 处理不完整**：越界区间会算出负的 Content-Length、
   后缀区间 `bytes=-N` 返回错段。
   → 越界回 416（带 `Content-Range: bytes */size`）、支持后缀区间。
   （曾表现为播放器停在 0:00/0:00 一直转圈。）
6. **夹具番剧详情路由丢失**：`anime_detail_page` 定义了但没接线，`/anime/<id>` 全 404。
7. **备份 payload 键名曾出现两套**（短名计数 + 长名数组）——已确认为设计内
   （计数与数据分离），保留并在文档中说明，避免误改。

## 环境教训（模拟器自动化）

- **点击坐标以 UI dump 的 bounds 为准**：同一屏幕上截图等比换算得到的 y 会比真实值
  偏大约 5%（本次 863→1950 实际命中下一行），dump 的 bounds 才是权威。
  **例外**：`Wrap` 布局的 chip（如倍速选项）dump 的 x 不可靠，用截图比例反而更准。
- `input text` **不支持非 ASCII**（中文会抛 NullPointerException），中文输入用
  剪贴板或改用 ASCII 测试串（本次用弹幕编号数字验证屏蔽词）。
- 安装后**首帧可能等 20 秒以上**，此期间的 `input tap` 会被丢弃——导航前先截图确认
  已渲染。
- 反复重启夹具服务会让模拟器侧残留连接，出现「请求已发出但一直缓冲」的假象；
  排查前先把夹具服务重启干净。

## 覆盖清单（4 例）

| 用例 | 断言 |
|---|---|
| 同运行器并发多调用、完成乱序 | slow 先发起后完成、fast 后发起先完成；两个 caller 各自拿到自己的结果（不串号），运行器随后仍可用 |
| 一个超时、另一个成功 | 挂起调用在 150ms 超时抛「超时」；**超时窗口内**的健康调用照常返回；超时后运行器仍可用 |
| JSON 不可序列化参数 | 传入不可编码的 Dart 对象 → 调用以异常收尾（jsonEncode 抛错在进入引擎前），运行器不受影响 |
| 复用 load 的状态隔离 | load A（counter=1）→ 调用正常；重新 load B → `hasFunction('onlyA')` 变 false（旧导出不残留）、`getCounter()` 返回 B 的 999（状态重置而非累加） |

## 测试设计

在 127.0.0.1 **随机端口**上用 dart:io 复刻 `tools/dev_fixture_server.py` 的
漫画页面形状（列表/搜索/详情/章节/图片），驱动**真实** `DeclarativeSource`
（`assets/rules/local-fixture.json` 的 baseUrl 替换为本地地址后解析）：

**用例 1：发现 → 详情 → 章节 → 正文全链路**
- 发现：`.list .item` 解析 3 条，remoteId 正则、标题、作者、url/封面绝对补全；
- 搜索：关键词回显（`/search?q=`）；
- 详情 + 章节：`h1`/`.summary` 字段 + `.chapters li` 的 5 话（remoteId `101-1`、
  绝对地址）；
- 正文：`#reader img@data-original/@src` 两条选择器得到 4 张绝对图片地址；
- 图片真实 HTTP 取回（PNG 魔数字节）。

**用例 2：离线缓存（产品链路而非仅解析）**
- 章节入 `DownloadRepository` 队列 → `DownloadService.run`（真实来源 provider）→
  4 张图片落盘到应用目录（tempdir）+ `DownloadManifest` 生成 + 任务转 done；
- 断言离线产物逐文件存在、漫画章节无正文文本（离线形态是图片目录）。

## 测试工程经验（后续同类复用）

`TestWidgetsFlutterBinding` 初始化后会把 `HttpOverrides.global` 换成「一律
400」的假实现，**任何** `HttpClient()` 构造都被劫持——绕过方法是在
`ensureInitialized()` **之前**捕获一个真实 `HttpClient`，经
`IOHttpClientAdapter(createHttpClient: () => captured)` 注入 dio。

## 覆盖清单（15 例）

- **漫画/图片**：列表分页链接、搜索回显、详情/章节结构、现场 PNG 魔数；
- **小说**：`/novel/list|{rid}|novelchapters|novelread` 四类页面状态与内容标记
  （含段内插图与缩进类名）；
- **番剧/放送表**：`/calendar` 是 Bangumi calendar 形状；播放页两条线路
  （mp4/HLS）——**弹幕地址不在播放页，而在规则 `content.danmaku`**
  （测试改为对规则文件断言，纠正了工作单假设）；
- **弹幕**：弹弹play 信封 `{code, comments:[{p,m}]}`，40 滚动 + 顶部(5) + 底部(4)；
- **视频 Range**：全量 200 与磁盘字节一致（`Content-Length` = 562487）；`bytes=0-99`
  → 206 + `Content-Range` + 精确字节；后缀区间 `bytes=-50`；跨末尾钳位；
  起点越界 → 416 + `Content-Range: bytes */size`；**非整数 Range 现状是连接
  被掐断**（粗糙点，已用 characterization 测试固化防止静默变化）；
- **弹弹play**：login 带/不带 `hash`、comment GET/POST、search 关键词回显；
- **追踪**：无 token → 401；`/v0/me`、收藏 upsert（**204**，官方是 202——差异
  已记录）、逐集 PATCH（204）→ `/tracking/state`（camelCase 键）回读 → reset 清零；
- **LK**：登录固定 `fixture-lk-key`；账号域**业务失败走 HTTP 200 + 信封 code**
  （空 key → `{code:401, message:"请先登录…"}`，与站点 pc-proxy 一致）；
  `/lk/state` 内存态；
- **WebDAV**：MKCOL 201/405、PUT 201、GET 往返、PROPFIND 207/404；
- **teardown**：`stop()` 做 shutdown + join + server_close + 删除临时目录；
  端口 0 随机分配不抢占 8123；全部请求断言只到 127.0.0.1。

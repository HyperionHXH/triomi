## 设计说明（不猜真实接口）

LK「发布管理」的真实端点在 `LkClient` 里**没有已验证的契约**（作品管理接口
未在 W6/W7 联调范围内，`lk_client.dart` 无对应方法）。按工作单要求：

- 页面只依赖 `LkWorksRepository` seam，**不猜**接口路径、字段名与分页语义；
- 默认实现 `LkWorksUnavailable` 把「未接入」呈现为可读错误态（含重试按钮），
  不崩溃、不假装空列表；
- Codex 落地真实适配器时只需实现 `LkWorksRepository` 并替换 provider 默认值，
  页面与测试零改动（测试用 `ProviderScope.overrides` 注入替身的模式与
  `lk_access.dart` 的「返回能力接口」约定一致）。

## 覆盖清单（6 例）

1. 列表渲染作品、更新时间、章数（缺字段降级「最近更新未知」）；
2. 触底分页：滚动到底加载第 2 页并追加；`hasMore=false` 后继续滚动不再请求；
3. 错误态显示来源错误文案 + 重试；重试成功恢复列表；
4. 空列表 → 空态提示「还没有发布作品」；
5. 默认 seam（未接入）→ 可读错误「…尚未接入」，不崩溃、不假空；
6. `LkWorksUnavailable.fetchPage` 抛 parse 类来源错误（单元级）。

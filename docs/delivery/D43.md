## 核对结论（旧备份调用兼容）

- Dart 侧 `platformChannel.writeToTree` 的 `mime` 参数缺省 `application/zip`；
- Kotlin 侧 `MainActivity.writeToTree` 读 `call.argument<String>("mime")`，
  缺省同为 `application/zip`；
- 备份页（`backup_page.dart`）的旧调用**不传 mime** → 两侧缺省一致 →
  SAF 建出的备份文档类型不变。**兼容确认 ✅**（静态核对，通道层行为有
  单测钉住）。
- EPUB/TXT 导出（Codex D29 接线）分别显式传 `application/epub+zip` /
  `text/plain`，D39 的 widget 测试已断言；本任务在通道层再钉一次。

## 覆盖清单（4 例）

1. 备份旧调用（不传 mime）→ 通道收到 `application/zip` + 完整参数
   （treeUri/fileName/bytes）+ 返回文档 URI；
2. EPUB：显式 `application/epub+zip` 透传；
3. TXT：显式 `text/plain` 透传；
4. 通道错误（`write_failed`）向上抛 `PlatformException`——**通道层不吞错**，
   `BackupService._writeOut` / `NovelExportService._writeOut` 依赖它做
   私有目录回退。

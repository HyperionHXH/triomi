## 覆盖清单（14 例）

**解析边界（ReaderContentParser）**：
- HTML 实体：十进制/十六进制实体解码、`&amp;` 系列具名实体、非法实体
  （`&#zzz;`）原样保留不吞字符；
- 图片地址：协议相对（`//cdn/...`）与 http 均升级 https；
- 缺尺寸/零/负尺寸插图：解析不崩溃，宽高比走 0.72 兜底（分页侧再钳位）；
- 标题/正文/段内插图按**文档顺序**混排；段内插图之后的文本不再带首行缩进；
- 空正文 → 「本章暂无正文」占位（无空页死循环）；
- 纯文本兜底的 `[res]` 资源标记替换为可读占位；
- 只有插图没有文本可解析可分页，页页非空。

**分页边界（paginateReaderBlocks）**：
- 长段落跨页切断：所有文本一字不差地分布在页面上（去掉首行缩进的
  「　　」显示装饰后逐字比对），页页非空，有限终止；
- 连续换行/空段：解析层过滤，不撑出空白页；
- 字号（14/20/16）与页面尺寸（320×640 / 300×600 / 220×420）三种样式下：
  页首块下标单调不减、全部落在合法区间、**任意合法块下标都能在某一页找到
  落点**（续读位置跨样式可恢复，这正是阅读器把进度存成块下标的理由）；
- **emoji 页面边界（D23-1 缺陷回归，当前失败，见缺陷报告）**。

**续读位置隔离（LibraryRepository）**：
- 不同来源同 ID：位置互不串（lk/1001 与 lns/1001 各自的 position）；
- 同书不同章：两章各一行、重复读同一章原位更新不倍增；`lastReadOf` 取
  最近一次（时间精度按秒存，测试用一次越过秒边界的等待构造确定性断言）；
- 「全部标为已读」只清本地未读提示：阅读历史原样保留（G2 语义）；
  **结构性证据**：`LibraryRepository` 不持有任何 HTTP 通道，markAllRead 是纯
  drift 更新，远端历史同步只在阅读器 `_persistProgress(commit: true)` 发生，
  与标已读无调用关系——本地提示不会被误写成远端历史。
  （unread_count 当前没有写入方——G1 缺口，测试用 SQL 模拟未来写入方。）

### D23-1（P3）分页页面边界会把 emoji 代理对切成半截字符

- **测试**：`带 emoji 的长段落：页面边界不得把代理对切成半截字符`
- **触发**：段落含 emoji 且页面较窄、文本恰好跨页（`paginateReaderBlocks`）。
- **预期**：每个页面片段自身是合法 UTF-16（不出现未配对代理）。
  **实际**：`safeEnd`（`novel_blocks.dart:376` 的
  `getPositionForOffset(...).offset`）落在代理对中间时直接
  `substring`，产生半截字符——所在页渲染为替换符（乱码），下一页以低代理开头。
- **影响**：显示级缺陷；内容拼接后仍然完整（无数据丢失），但阅读体验受损。
  纯 ASCII/中文正文不受影响；日文区用户与含 emoji 的网文正文会命中。
- **建议**：`safeEnd` 计算后做一次代理对回退（若 text.codeUnitAt(safeEnd-1)
  是高代理或 text.codeUnitAt(safeEnd) 是低代理，则 safeEnd±1 对齐）。
  生产代码改动归 Codex。

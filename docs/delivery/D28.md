- 工作单提示的 `^1.2.8` 约束**不存在可解析版本**——pub 给出的可解析建议是
  `^1.0.11`（官方 `media_kit 1.2.6` 文档的 libs 配套版本线）。已按 1.0.11 锁定；
  升级 media_kit 本体时需同步评估 libs 版本。
- 与 D26 盘点一致：该包提供 media_kit 在 Windows 上的 libmpv 原生库；
  缺它时桌面播放不可能出画（`player_page.dart` 桌面走 media_kit 路径）。

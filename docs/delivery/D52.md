## 覆盖清单（5 例）

| 用例 | 断言 |
|---|---|
| 第 2 类行失败（libraryEntries 的 progress 类型错误） | 事务里先写入的 mediaItems 随失败**整体回滚**（count=0）；设置补偿恢复旧值并删除新增键 |
| 第 3/4 类行失败（histories 的 position、chapterRows 的 sortIndex 类型错误） | 四张表全回滚；设置完整补偿（本机无旧键 → 导出为空） |
| 旧值为 null vs 键不存在 | `MemBox` 前置确认能区分两者；导入前存在但值为 null 的键补偿后**仍存在且值为 null**（不是新值、不是被删）；导入前不存在的键补偿后**不存在**（删除而非写 null） |
| 零设置导入 | settingsValues 为空 + 库失败：补偿是安全空操作，设置保持空、库回滚 |
| 补偿自身失败（restoreSubset 必抛替身） | 导入仍以异常收尾（不吞错、不假成功），库事务自身回滚——**可终止复现**，持久恢复协议（崩溃后补偿、补偿重试、并发导入串行化）交 Codex D60 |

失败注入方式：利用各循环行的字段类型断言（如 `progress: '不是数字'` →
`as num?` 抛 TypeError），在 payload 层即可精确选择第 N 类写入失败，
不需要动 drift 拦截器。

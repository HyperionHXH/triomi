## 覆盖清单（4 例）

1. **SAF 目录选择取消**：`pickDirectory` mock 返回 null → 不调用
   `writeToTree`、成功 snackbar 显示私有目录回退路径、磁盘上真实落盘；
2. **EPUB MIME 契约**：选择授权目录后导出 → `triomi/platform` mock 收到
   `mime: 'application/epub+zip'`、`fileName: '导出小说.epub'`、授权 treeUri，
   snackbar 显示授权 URI；
3. **TXT MIME 契约**：同上，`mime: 'text/plain'`、`.txt`；
4. **授权目录写入失败回退提示**：mock 抛 `PlatformException` → 导出成功
   （不报失败）、snackbar 显示私有目录回退路径、不显示写失败的授权 URI。

测试结构：`sourcesProvider` 用 StubSources 注入实现了 DetailProvider +
ContentProvider 的小说夹具源；`databaseProvider` 注入内存库；
`triomi/platform` 与 `plugins.flutter.io/path_provider` 两条通道 mock；
私有目录指向 tempdir。

## 测试工程经验（记录给后续同类用例）

- 导出进度对话框含无限 `CircularProgressIndicator`，`pumpAndSettle` 会超时；
- **回退路径含真实文件 IO**（`File.writeAsBytes`），在 widget 测试的
  FakeAsync 区不会被 `pump` 推进——需要 `tester.runAsync` 与 `pump` 交替
  轮次（微任务链 pump 冲洗发起 IO → runAsync 让 OS 完成 IO → pump 送达回调），
  连续 3 次运行稳定全绿；
- mock 通道方法名以 `path_provider` 实际发出的为准
  （`getApplicationDocumentsDirectory`）。

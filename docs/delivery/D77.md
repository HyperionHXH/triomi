## 设计说明

- 目录数据走 `sourceCatalogLoaderProvider` seam（默认实现待 main() override，
  届时指向随包 asset 或远程 raw JSON——两者用同一协议）——测试注入替身，
  不访问网络；随包目录索引文件尚未登记（真实条目必须是合法授权来源，
  内容决策归 Codex），因此本文件不引用具体 asset 路径。
- 安装 = 下载条目 `url` 的规则 JSON → 既有 `SourceRegistry.importFromText`
  （repoUrl 记录条目地址）——**不复制导入逻辑**；规则必须通过 schema 校验
  （自检失败会以具体原因显示在卡片上）；
- 已安装判定来自 `sourcesProvider` 快照的真实来源 id（安装成功后按钮变
  「已安装」），重复安装由来源 id 幂等（upsert）兜底；
- 手工 URL/JSON 导入路径（`sources_page.dart`）未改动。

## 覆盖清单（5 例）

1. 分组渲染：番剧/漫画分组标题、名称、版本、许可证、能力标签；
2. 安装成功：规则下载 → 入库 → 「已安装」+ toast，请求 URL 为条目 url；
3. 安装失败：卡片显示具体原因（HTTP 404），按钮回「安装」可重试；
4. 目录加载失败可重试；空目录有明确提示（重试确实重新加载）；
5. 协议解析单一入口（loader 与 D76 的 parse 共用）。

# D61：TTS 长段与滚动定位

状态：Codex 已实现，待 Flutter 环境复验。

## 实现

- `TtsPlan.of` 增加默认 1800 字符上限；超长标题/段落按空白或标点优先切分，无法找到自然边界时硬切。
- 分块保留原 `blockIndex`，只有原段最后一块保留段后停顿，避免阅读锚在分页或朗读块之间漂移。
- 小说滚动模式为每个正文块建立稳定 `GlobalKey`，TTS 进度变化时调用 `Scrollable.ensureVisible` 定位当前块；分页模式继续按页元素定位。
- 保留停止、换章、后台、繁简切换和 token 迟到回调保护。

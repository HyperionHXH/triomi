## 设计说明

- 契约与 `BackupService.exportToFile`（T7-4 设备验证过的 SAF 路径）完全一致：
  `Future<void> Function(String uri, String fileName, List<int> bytes)`，
  上层（导出页）接 `platform_channel.dart` 的 `writeToTree` 即可复用既有
  授权目录选择器。
- SAF 路径返回 `'$directoryUri/$name'` 作为逻辑路径（与备份服务同款约定）；
  SAF 无目录列举能力，同名冲突由调用方（SAF 选择器覆盖确认）决定，
  私有目录回退保留 `(1)` 序号。
- **未实现 Windows SAF**（工作单边界）：Windows 上不提供注入器即始终走
  私有目录路径。

## 覆盖清单（4 例）

1. EPUB：授权目录优先——`writeToTree` 收到正确文件名与字节、返回授权 URI、
   私有目录不落文件；
2. TXT 同样支持注入（文件名/UTF-8 字节/路径）；
3. SAF 写入失败（权限被回收）→ 回退私有目录且文件可读、路径在文档目录下；
4. 未提供授权目录（用户取消/未选择）→ 不调用注入器、走私有目录。

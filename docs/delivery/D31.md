## 设计决策（对齐 TTS_RESEARCH 与批次基线）

- **utterance 粒度 = 段落**（批次基线第一版决策）：`TtsPlan.of(List<ReaderBlock>)`
  标题/段落取原文，标题后带停顿；**分页是渲染层概念**，跨页句子按块拼接，
  本层不感知分页——TTS_RESEARCH 第 3 节约束「不能一页一个 utterance」由此满足。
- **插图占位**：`IllustrationBlock` → 「插图」替换词 utterance（`isPlaceholder`
  标记），朗读执行但**不推进阅读锚**（锚 = 最近一个非占位块下标），遵守
  研究文档「占位不计入进度锚，否则位置漂移」的约束。
- **位置锚 = 块下标**：复用阅读器 `_progressParagraph` 的锚模型（typedef
  `TtsAnchor`），不发明第二套位置模型；繁简转换一致性问题（offset 映射）
  不在本层（无逐词高亮 = 无 offset 需求）。
- **锁定章拒绝**：`start(locked: true)` 抛 `StateError`、引擎**零调用**、
  状态置 error——「不解锁不缓存」红线在朗读域的镜像；空块序列（锁定章
  天然不渲染正文）走 completed 兜底，不会为朗读实现任何取数路径。
- **暂停降级**：引擎 `pause()` 返回 false（Android workaround 不可用等）时，
  控制器按「停止当前段、恢复时重读」降级，第一版基线的前台/无高亮策略不变。
- **生命周期边界**：本层只管会话状态机；音频焦点、前台服务、与
  `keepScreenOn` 联动、阅读器接线全部留给 Codex（D37）。

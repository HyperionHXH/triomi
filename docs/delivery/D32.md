## 基线回顾（已确定，本轮只补测试）

- 首次缓存目录**不产生**未读；之后只按新增章节 `remoteId` 累计；
  重复刷新不重复累计（既有 1 例覆盖，保留）。
- 本轮补齐的边界：

| 用例 | 断言 |
|---|---|
| 目录缩减（下架章节） | unread 不增不减——缩减只影响目录行，提示是已累计的阅读决策 |
| 重排（remoteId 集合不变） | 不累计；且 sortIndex 重排后按新顺序读回 |
| 未加入书架的作品刷新目录 | 不崩溃、不产生孤儿书架条目 |
| `markAllRead()` 全清 | 返回值 = unread>0 的条目数（不含未读为 0 的）；全 0 后返回 0 |
| `markAllRead(sourceId:)` 按来源 | 只清指定来源，其他来源未读保留 |

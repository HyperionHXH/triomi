# D91：本地追番与统一阅读书架边界

状态：Codex 已完成实现与离线回归（2026-10-05）。

## 审核发现与决定

GLM 的发现优先导航和漫画/小说过滤正确，但动画详情「去追番」及兼容空态误指 `/tracking` 远端账号设置，点击并不能收藏。使用占位路由的测试只证明跳转，不能证明持久化。

采用共享物理收藏表、按类型分业务视图，避免无必要的数据搬迁。旧 `anime` 条目直接可见，复合键、加入时间、集数进度、观看秒数、缓存目录与历史继续有效。决定见 [ADR](../adr/ADR-2026-10-05-discover-first-reading-library.md)。

## 最终实现

| 文件 | 变化 |
|---|---|
| `library_repository.dart` | `addAnimeFollow` 类型约束、`listAnimeFollows`、`watchAnimeFollows`；事务内幂等加入，不重置已有状态；`markAllRead` 支持类型范围 |
| `library_providers.dart` | 本地追番数据库流，收藏/取消/观看进度变化会刷新列表 |
| `detail_page.dart` | 动画「加入追番 / 已追番 · 取消」持久化，busy 防重复，失败可重试；不依赖远端账号 |
| `schedule_page.dart` | 默认「我的追番」，列表离线可见、点击原来源详情、集数角标、长按确认取消；放送表选中才加载网络 |
| `library_page.dart` | 兼容空态去真正追番页；全部标已读只作用于当前阅读范围，默认不清动画未读 |

取消追番只删除收藏关系，保留缓存和观看历史。漫画/小说仍可本地收藏，并按原能力和会话选择同步站点书架。兼容筛选「番剧（旧）」仍在，因共用存储也能显示新动画；不需要迁移工具。

## 边界与诚实声明

- **本机验证 ≠ 远端 CI 通过**：`python-tools` job 的 GitHub Actions 结论要等
  推送后才存在，本交付只声明本地命令退出码，不写「CI 已通过」。
- 干净 checkout 场景用 tempdir 模拟验证（仓库外脚本不被自动拾取、无噪音
  finding）；真实仓库根目录外的 `_e2e_*` / `_video_check.py` 在默认扫描下
  零影响。
- 编号歧义的区分粒度是**章节标题**：若未来把旧工作单清单放进带「清单」字样
  的标题下会漏报，目前三类当前文档（AFTER_M5_PLAN / handoff README /
  PROJECT_SPEC）的章节结构已核对无此情形。

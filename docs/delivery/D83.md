## 覆盖清单

**发现页 widget（4 例）**：
1. 无来源 → 「还没有可用的来源」+ 管理来源引导；
2. 仅资料源（只有 search/detail 能力）→ 来源出现在发现页但提示
   「该来源没有可用榜单，试试搜索」（合同：资料源可搜索资料，无榜单）；
3. 多来源切换：来源 chips 切换后重新加载对应榜单；
4. 类型过滤：多类型并存出现「全部/漫画/小说」；过滤后其他类型来源隐藏、
   榜单收窄；「全部」恢复。

**来源页 widget（1 例）**：能力标签可见性——资料源只有「搜索·详情」、
不含「正文」（无播放能力对用户可见，呼应 CORE 计划的产品文案要求）。

**UTF-8（2 例 Python）**：全量跟踪文本文件 UTF-8/无替换字符；合成坏字节
被抓到。命令行扫描保持 `python tools/check_text_encoding.py`（exit 0）。

## 扫描规则（与 D14/D15 的漂移扫描互补）

| 规则 | 级别 | 说明 |
|---|---|---|
| `missing_delivery` | error | `GLM_BATCH_*.md` 任务表里的每个任务号（`\| DNN \|` 行）必须有对应的交付文档（docs/delivery/ 下与任务号同名的 md） |
| `missing_summary` | error | 批次必须有覆盖全部任务的 `BATCH_*_SUMMARY.md`——**合并汇总也算**（如 D15–D26 一份覆盖 D18–D26：文件名区间包含或内容提及全部任务号均可） |
| `broken_reference` | error | 交付文档里反引号引用的仓库路径（`test/` `lib/` `tools/` `docs/` `assets/` `android/` `windows/` `.github/workflows/`）必须真实存在（通配 `*` 与目录引用跳过）——交付文档的「证据」不能指向不存在的文件 |
| `missing_section` | warning | 交付文档缺「任务 / 完成范围 / 验证」任一模板段（结构不完整是警告；BATCH 汇总不套单任务模板） |

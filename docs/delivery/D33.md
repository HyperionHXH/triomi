## 审计结论（交 Codex D35 决策）

1. **跨存储原子性缺口（结构性，未改）**：`_apply` 中数据库事务先提交、
   `preferences.importAll` 在事务外执行——设置导入失败时库已提交（本轮
   两条「部分成功窗口」用例固化该现状）。修复方向：设置导入包进同一事务
   （Hive 无事务语义，可能需要「先写设置、失败则回滚库」的补偿式提交）
   或接受现状并在 UI 提示「设置导入失败，数据已导入」。
2. **设置的部分写入窗口**：importAll 逐键 put，中途失败留下前缀状态。
   若采纳补偿式提交，importAll 应先在内存汇总再一次性写入（MemBox 语义
   已可支撑单测）。
3. 缺时间戳最旧策略现在对 libraryEntries 与 histories 两条数据轴都有测试；
   chapterRows 无时间戳列（跟随作品 updatedAt），无需类似策略。

## 覆盖清单（6 例）

**带令牌的完成回调**：
1. 令牌与活动 speak 配对 → 正常推进到下一段；
2. **seek 后旧令牌迟到完成被丢弃**：seek 前的 speak 令牌（1）在 seek 后
   到达 → 不推进；当前令牌（2）的完成正常收尾（seek 先 stop 当前段也被断言）；
3. **stop 后迟到完成被丢弃**：带令牌与无令牌两种形态都不推进、状态保持
   idle、没有新的 speak；
4. 无令牌回调的**文本校对**路径：旧文本的迟到回调被丢弃，匹配文本正常收尾
   （覆盖不支持令牌的旧插件的降级安全）。

**speak 抛错收口**：
5. start 时 speak 抛错 → error 态、引擎零受理（spoken 为空）、错误态下迟到
   完成不推进；
6. 中途 speak 抛错 → 停在 error、已读段落不回滚（锚保持在第二段）。

## 协议要点

- **必填**：id/name/type/version/url/capabilities；可选：hash/license/updatedAt；
- **url** 必须是绝对 http(s) 地址（指向规则 JSON 本体；下载安装走既有
  `SourceRegistry.importFromText/Url`，D82 负责安全校验）；
- **同仓库 id 重复** → 解析期拒绝（一次报出全部问题，不是修一个报一个）；
- **未知能力/type/version 形状** → 协议错误（避免静默丢能力导致 UI 显隐错）；
- 索引既支持随包 asset，也为 HTTPS raw JSON 预留同一格式（协议无本地路径概念）；
- 解析失败抛 `SourceCatalogParseException`（problems 列表），安装侧按
  SourceException 同级展示。

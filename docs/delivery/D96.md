## 测试过程记录（非生产缺陷）

- drift 流（`watchAnimeFollows`）在 provider dispose 时经
  `StreamQueryStore.markAsClosed` 调度零时长 Timer；树拆除阶段才 dispose
  会触发 pending-timer 断言。测试改用显式容器在测试体内 dispose 并 pump，
  不改生产代码。
- 文件库 teardown 顺序（LIFO：后注册先执行）必须先关库后删目录，
  否则 Windows 上删除抛 `PathAccessException`。

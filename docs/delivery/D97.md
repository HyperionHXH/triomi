## 测试基建说明

- 走**在线加载路径**（`_NoDownloads.localImageDir` 恒 null），
  `ContentProvider.content` 由脚本化替身供给，每章一个行为队列；
- 图片用真实 1x1 PNG 的 `file://` URI：widget 测试内 `Image.network`
  一律 400（binding 劫持），会产生大量被记录的异常污染 `takeException`；
  真实文件图让断言聚焦在**状态与时序**，不依赖外网；
- **预取消费队列**是真实行为：每章加载完 `_preloadNeighbour` 会预取
  下一章，各消费一条脚本记录，测试按此编排（慢响应场景预取/加载
  各持一个 Completer）。

## 覆盖清单（6 例）

1. **换章慢响应**：加载期「正在加载章节…」、无滑杆、无 0/0；完成后
   新章标题与 `1/3` 可见，恢复位置 0 以复合键落库；
2. **旧响应晚到**：切到 c2（慢）再立即切到 c3（即时），c2 的响应随后
   才完成 → 被加载序列号丢弃，界面保持 c3（`1/2`），且 c2 不产生任何
   进度记录（保存队列的 loading 守卫）；
3. **失败后重试**：首次 `SourceException(auth)` → 错误文案与重试按钮；
   重试走同一 `_load` → 成功显示 `1/5`，进度照常落库；
4. **单图片章**：滑杆 min=max=value=1 不越界（不恢复 0/0 或 1/0 显示）；
   末页再翻进入下一章；c1 进度记在 c1 名下（复合键不串号）；
5. **短章夹紧**：预置超出章长的历史位置（10）→ 打开夹紧在最后一页
   `3/3`；
6. **末页重复点击**：最后一章末页再翻 → 「已经是最后一章」提示；
   重复触发不崩溃、不重复入队。

测试显式设 LTR 模式（默认 RTL 下 right=上一页，语义会反转）；
翻页动画 180ms 用显式 pump 推进时钟，避免遗留 ticker。

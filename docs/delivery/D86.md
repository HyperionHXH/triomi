## 覆盖清单（9 例）

**协议解析（2 例）**：`asset://` 随包地址被接受；`ftp://` 等不支持的
协议被拒绝。HTTP/HTTPS 边界与未知能力沿用 D76 的
`test/source_catalog_test.dart`（坏 url / `能力未知` 用例已在）。

**安装安全（7 例 widget）**：
1. `asset://` 成功安装：全程 `http.requests` 为空（不触网），安装后
   规则入库、UI 变「已安装」；条目选 `mangadex`（随包资产但不在内置
   播种清单，安装前后可分辨）；
2. `http://` 条目在**发起请求前**被拒绝（替身收到请求即抛错验证），
   显示「远程来源目录只允许 HTTPS 地址」，可重试，库内无记录；
3. `https://` 成功路径（带正确 SHA-256）：入库 + 「已安装」+ 请求 URL 断言；
4. 超过 2 MiB 的规则文本：显示「规则文件超过 2 MiB 限制」，注册表
   **无半安装记录**，仍可重试；
5. SHA-256 不匹配：显示「规则文件哈希校验失败」，库内无记录；
6. 已安装条目只读展示：pump 前预置同 id 规则，目录直接显示「已安装」；
   点击「已安装」文本不产生新请求（`http.requests` 仍为空）；
7. 安装失败后重试：首次 503 失败原因可见，重试成功入库。

## 过程记录：测试间污染与修复

build 退化为纯内存库微任务，全部用例确定化。未改动生产代码。

# Triomi repository instructions

Preserve existing uncommitted work. Do not reset, clean, switch branches, or
commit automatically. Keep reference repositories read-only. Specify the ADB
device explicitly, preserve application data, and keep credentials out of
source, APKs, logs, screenshots, and evidence.

## Agent skills

### Issue tracker

Current work is tracked locally in `docs/ROADMAP.md` and `docs/CURRENT_STATUS.md`;
do not create remote issues for this task. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical role names when a future triage task needs labels.
See `docs/agents/triage-labels.md`.

### Domain docs

Single repository context: current status, roadmap, capability matrix, and
relevant ADRs. See `docs/agents/domain.md`.

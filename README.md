# Triomi

**追番 · 漫画 · 小说，一个客户端。**

Triomi 是一款面向 Android、Windows 与 iOS（侧载）的开源聚合客户端，把看番、看漫画和读小说放在同一个应用里。你可以浏览作品、选择来源、管理收藏，并在播放或阅读后继续上次进度。

应用分为「追番 / 漫画 / 小说 / 我的」四个工作区：各自保留搜索、来源和阅读偏好，历史、下载与备份则集中管理。手机和桌面使用同一套数据与功能，界面根据屏幕大小调整布局。

[下载应用](https://github.com/HyperionHXH/triomi/releases) · [更新记录](https://github.com/HyperionHXH/triomi/releases) · [使用与支持范围](docs/CURRENT_STATUS.md)

## 能做什么

### 追番

- 浏览推荐与放送时间表，查看作品简介、角色、制作人员和公开评论。
- 选择播放站点与剧集，支持倍速、字幕、画幅调整、手势控制和进度恢复。
- 从 **B站、Gamer 动画疯、Animeko** 获取只读弹幕，可独立开关、纠正分集和调整时间偏移。
- 自定义弹幕区域、字体、颜色、密度和去重，管理关键词与安全正则屏蔽规则。
- 管理追番收藏，配置 WebDAV 后自动同步收藏和观看进度，可独立开启 Bangumi 收藏同步。

### 漫画

- 通过兼容的来源与扩展浏览、搜索漫画，管理书库分类和更新。
- 阅读条漫或分页漫画，调整双页、裁边、滤镜与作品独立设置。
- 导入本地 CBZ/ZIP、图片或图片目录，继续离线阅读。
- 用 WebDAV 自动同步收藏、章节和页码；缺少原扩展时提示安装，或核对作品后迁移到其他来源。

### 小说

- 浏览轻之国度、轻书架及兼容来源，使用对应站点账号与书架。
- 支持左右翻页、卡片翻页和上下滚动，自定义字体、行距、页边距与背景。
- 保留来源专用字体和阅读进度，在来源允许的范围内缓存或导出内容。

### 日常管理

按剧集或章节选择下载，查看观看与阅读历史，备份收藏、设置和进度；需要迁移离线内容时，可明确选择包含下载媒体。应用内提供版本检查与缓存管理，更新和清理均保留用户确认。

## 下载与安装

在 [GitHub Releases](https://github.com/HyperionHXH/triomi/releases) 下载，版本变化统一查看对应发布说明。

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| Android 7.0 及以上 | `triomi-android.apk` | 下载后安装；同签名正式版可覆盖更新 |
| Windows x64 · 绿色版 | `triomi-windows.zip` | 完整解压后运行 `triomi.exe`，不要只复制 EXE |
| Windows x64 · 安装版 | `triomi-windows.msi` | 当前用户安装，支持开始菜单入口与覆盖升级 |
| iOS 15.0 及以上 | `Triomi-iOS-Unsigned.ipa` | 通过 AltStore / SideStore 等签名侧载；不能直接点开安装 |

Windows 两种形式任选一种，完整包已包含漫画扩展所需的兼容运行时，无需另装 Java。Windows 包尚无 Authenticode 发布者签名，可能提示未知发布者；请从本仓库下载，并用随附的 `SHA256SUMS.txt` 核对文件。

iOS 15+ 使用 `feat/ios` 的原生 AVPlayer 后台音频/画中画、WebKit JS 与下载恢复。iOS 安装包需要侧载签名，Mihon APK/DEX 不在 iOS 执行；构建与设备验证边界、下载和安装步骤见 [iOS 适配与侧载指南](docs/IOS_ADAPTATION.md)。

> **旧版 Android 升级：** 构建号 165 及更早版本使用旧签名，不能直接覆盖。请先将备份导出并复制到应用目录之外，确认可恢复后再迁移；未备份时不要卸载或清除数据。166 及之后的同签名正式版可直接覆盖更新。

## 开始使用

1. **选工作区**：进入追番、漫画或小说，浏览作品或搜索名称。
2. **配置来源**：从该工作区顶部齿轮进入设置；番剧规则仓库与漫画扩展仓库分别管理，不能混用。
3. **开始观看或阅读**：番剧先选站点与剧集，漫画和小说从目录选章；账号按站点需要配置，不是所有内容都必须登录。
4. **管理个人内容**：在「我的」查看历史、下载、备份与通用设置。

第三方扩展包含可执行代码，只安装并启用你信任的来源。站点失效、内容下架、地区或账号限制都可能影响使用；兼容仓库不代表仓库中的所有来源都能工作，弹幕也不保证覆盖每部作品。

## 开发

项目使用 Flutter / Dart。当前构建环境为 Flutter 3.47.5；Android 需要 JDK 17 与 Android SDK，Windows 需要 Visual Studio 2022 的 C++ 桌面开发环境。

```shell
flutter pub get
flutter run -d windows
flutter analyze
flutter test
```

Windows 完整 ZIP/MSI 打包使用 `tools/package_windows.ps1`，另需 JDK 21、Python 3.12+ 与 .NET 10 SDK。Android 正式发布需要已有签名配置，普通 Actions 验收包不能用于覆盖正式签名安装。
